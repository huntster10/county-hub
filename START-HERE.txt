COUNTY HUB - HOW TO RUN IT ON YOUR OWN COMPUTER (localhost)
===========================================================

WINDOWS:  double-click   start-windows.bat
MAC:      double-click   start-mac.command
          (first time only: right-click it -> Open -> Open, because it is
           not from the App Store)

What happens:
  1st double-click  -> it creates a settings file called .env.local and opens
                       it for you. Paste in your Supabase values (the same five
                       you typed into Vercel) and save. See .env.example for
                       what each line means.
  2nd double-click  -> it downloads the project's parts (one time, 1-3 min),
                       starts the site, and opens http://localhost:3000 in
                       your browser.

Keep the black window open while you use the site. Close it to stop.

"localhost" means the site only exists on THIS computer. Nobody else can
visit it. For a real address your members can use, use the Vercel site:
https://county-hub.vercel.app
